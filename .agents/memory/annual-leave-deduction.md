---
name: Annual-leave deduction
description: The product rule for when annual leave is deducted from an employee balance.
---

Deduct annual leave only when an annual-leave request is approved or a manager explicitly grants/records the leave. Absence, missing attendance, and permission approval alone must never create annual-leave deductions.

**Why:** The user clarified that balance deduction is tied to approved leave or an explicit manager decision, not attendance events.

**How to apply:** Keep deduction in the approved annual-leave request and manager-grant flows. Do not trigger it from attendance or permission calculations; canceling an approved request must restore the deducted days.
