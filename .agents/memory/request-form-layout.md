---
name: Leave and permission request form layout
description: The employee-facing presentation rule for leave and permission requests.
---

Show leave and permission request forms as a compact on-page card, not over a dimmed modal backdrop. Avoid an inner scroll area and keep the fields visible together on normal screen sizes.

**Why:** The user said the dark overlay caused the form to appear clipped and explicitly asked for no scroll.

**How to apply:** When updating this request flow, keep the form in the page layout and do not add a nested scrolling container. Let the responsive page flow handle exceptionally short viewports.
