PART 5 — RULES, OVERTIME & PAYROLL

Part 5 should build the rules engine and payroll foundation on top of the completed Attendance, Leave, GPS, and employee systems.

The goal is to make VAR HR calculate attendance consequences and payroll transparently from configured company rules instead of hard-coded values.

1. Attendance Rules

Implement company-configurable rules for:

- Work start time.
- Work end time.
- Daily required hours.
- Allowed late/grace period.
- Late calculation.
- Early checkout calculation.
- Absence rules.
- Working days.
- Weekly schedule.
- Holidays.
- Shifts where supported.
- Overtime eligibility.
- Overtime start threshold.
- Overtime calculation method.

Rules must be company-scoped.

Do not hard-code one company's rules into the application.

2. Overtime

Implement a proper overtime foundation.

The system should be able to determine:

- Regular worked hours.
- Overtime hours.
- Late minutes.
- Early checkout minutes.
- Missing hours.
- Overtime eligibility.

The calculation must be explainable.

Do not simply store a final overtime number without preserving enough information to explain how it was calculated.

3. Payroll Foundation

Build the first real payroll calculation layer.

Payroll should consider the completed systems:

- Employee salary.
- Attendance.
- Absence.
- Late time.
- Early checkout.
- Leave.
- Permissions.
- Overtime.
- Additions.
- Deductions.

The result should include at minimum:

- Gross/base salary.
- Additions.
- Deductions.
- Attendance-related deductions where configured.
- Overtime amount.
- Final/net salary.

Most importantly:

The system must be able to explain HOW the final salary was calculated.

Example:

Base salary

+ overtime
+ additions
  − late deduction
  − absence deduction
  − other deductions
  = net salary

Do not hide the calculation behind a single unexplained number.

4. Payroll Periods

Implement company-scoped payroll periods where missing:

- Period start.
- Period end.
- Status.
- Employees included.
- Calculation state.
- Finalization state.

Support a safe lifecycle such as:

Draft → Calculated → Finalized

Do not make finalized payroll silently change when attendance data changes.

5. Payroll Calculation Snapshot

When payroll is calculated/finalized, preserve the calculation inputs/results required to explain the result later.

A historical payroll record must not depend entirely on today's attendance rules.

Do not destroy or rewrite historical payroll calculations when company rules change.

6. Additions & Deductions

Implement the foundation for:

- Fixed additions.
- Variable additions.
- Fixed deductions.
- Variable deductions.
- Employee-specific adjustments.
- Company-level rules where appropriate.

Every adjustment should have:

- Amount.
- Reason/type.
- Employee.
- Payroll period.
- Company.
- Audit information where the existing architecture supports it.

7. Authorization

All payroll and rule operations must be server-side authorized.

Expected boundaries:

Employee

Can see only their own permitted payroll information.

Cannot:

- Modify company payroll rules.
- Modify another employee's salary.
- Finalize payroll.
- Manage company deductions/additions.

Manager

Can see only the employees within their authorized scope where the existing role model permits it.

Cannot automatically access the entire company's payroll.

Owner

Can manage:

- Attendance rules.
- Overtime rules.
- Payroll periods.
- Payroll calculations.
- Additions.
- Deductions.
- Company payroll configuration.

Cross-company access

Must always be rejected.

Do not rely only on frontend visibility.

- Payroll periods.
- Payroll calculation.
- Employee payroll details.
- Additions.

Preserve the existing VAR HR visual language.

Do not redesign unrelated screens.

9. Payroll Breakdown

The employee payroll view must clearly show the calculation.

For example:

Base salary: 10,000 EGP
Overtime: +500 EGP
Additions: +300 EGP
Late deductions: −250 EGP
Absence: −500 EGP
Net salary: 10,050 EGP

Use the actual calculated values, not hard-coded examples.
